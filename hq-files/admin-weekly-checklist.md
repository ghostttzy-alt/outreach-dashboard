# Admin Add-On: Weekly Checklist

This is the step-by-step checklist a future Claude session follows each week for one Admin Add-On client.

## Before Starting

- [ ] Read the client's notes in HQ (business name, Google Business Profile URL, website URL, tone preferences)
- [ ] Check if the client emailed any specific update requests this week

## Every Week

### Google Business Profile (takes ~10 min)

1. Open the client's Google Business Profile
2. Check for new reviews since last week
   - If there are positive reviews: write a short, genuine thank-you reply (1-2 sentences, use the reviewer's name if given, mention a specific detail they said)
   - If there are negative reviews: flag for the client in HQ with the review text — do not respond without their input
3. Write this week's GBP post:
   - Use one of these formats (rotate): tip about their service, behind-the-scenes fact, seasonal mention, product/service highlight
   - Keep it under 150 words, friendly and local
   - Do not use hashtags on GBP (they don't work there)
   - Post it, or save the draft text in HQ if you can't post directly
4. Check "Updates" section — make sure hours are current

### Website Updates (if requested or scheduled)

1. Check the client's site for obvious problems (broken images, wrong phone number visible)
2. Apply any updates the client requested this week
3. Log what was changed in HQ (date, what was changed, 1 line)

### Monthly Report (first week of each month only)

Write a 1-paragraph email to send the client:
- What was updated this month
- How many GBP posts were made
- Whether any reviews were replied to
- One positive note (e.g. "Your hours are showing correctly across Google now")
- Keep it under 100 words, plain language, no corporate speak

## After Each Week

- [ ] Log the completed tasks in HQ (venture: Web Design + Care Plans)
- [ ] Note anything the client asked for next week
- [ ] If the client hasn't responded to emails in 2+ weeks, flag it in HQ as "Check in needed"
